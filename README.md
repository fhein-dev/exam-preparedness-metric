# exam-preparedness-metric
A simple exam preparedness metric that can be ran locally (can also be used as a template for other exams). It uses cross-domain quiz output and standard to high difficulty practice examination output to evaluate exam preparedness. This was made with the ISC2 CC exam in mind so no simulated laboratory questions are present. *yet

**future plans**
> simulated laboratory environment and performance based questions
> manual input of questions without code
> availability for other common industry-recognized certifications
> lightweight locally run a.i agent for generating new questions
